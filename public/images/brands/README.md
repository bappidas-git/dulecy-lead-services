# Brand logos

Drop partner-brand logo files here. The Brands section (prompt 09) reads
`logoFile` paths from `src/data/brandsData.js` and, when a file is present,
renders the image; when it is missing, it falls back to a styled text
wordmark — so these files are optional and no placeholders are needed.

## Format

- **Type**: transparent PNG
- **Recommended size**: ~360 × 140 px
- Use the brand's official logo on a transparent background, trimmed of
  excess padding.
